# Final_Project — 사거리 신호등 제어기

콤보박스 확장 포트의 신호등 모듈(Combo II-DLD Traffic lights module)로 사거리 신호를 제어하는 기말 프로젝트입니다. 주간·야간 시퀀스, 황색 신호, 보행 신호 점멸, Text LCD 시계·상태 표시, 시간 배율, +1시간 버튼, 긴급 차량 수동 조작을 구현했습니다.

교안: `보고서/Final_Project/교안_프로젝트.pdf` (핀 맵 p.3, 기능 p.4 ~ 6, 스테이트 A ~ H p.8 ~ 15). 시연 12/8, 결과 보고서 12/14.

## 동작

### 시퀀스

| 구분 | 시간대 (시계 기준) | 순서 | 스테이트 1개 |
|---|---|---|---|
| 주간 | 08:00:00 ~ 22:59:59 | A → D → F → E → G → E → (A ...) | 5초 + 황색 1초 |
| 야간 | 23:00:00 ~ 07:59:59 | B → A → C → A → E → H → (B ...) | 10초 + 황색 1초 |

- 스테이트 시간과 황색 시간은 **실제 시간**입니다. 시계 배율을 바꿔도 신호 시간은 그대로입니다.
- 리셋을 풀면 그때 시각에 맞는 시퀀스의 첫 스테이트(주간 A / 야간 B)부터 시작합니다.

### 한 스테이트의 시간 흐름 (주간 A → D 예)

```
0 s           2.5 s                    5 s        6 s
|  A 그대로    |  A, 보행 초록 점멸        |  황색      |  D ...
|             |  (0.5 s 꺼짐 / 0.5 s 켜짐) |  A → D     |
```

야간은 10초, 점멸은 5초부터입니다.

### 황색 신호 (스테이트 사이 1초)

차량 신호등마다 지금 스테이트(from)와 다음 스테이트(to)를 비교합니다.

| 램프 | 황색 1초 동안 |
|---|---|
| 빨강 | from에서 빨강이면 그대로 빨강 (초록이 켜질 때까지 빨강 유지) |
| 노랑 | from에서 켜진 초록 / 좌회전이 to에서 꺼지면 켜짐 |
| 초록, 좌회전 | from과 to 둘 다 켜진 것만 켜 둠 |

예: A → D 북쪽 `초록 → 노랑 → 좌회전`, B → A 북쪽 `초록+좌회전 → 초록+노랑 → 초록`, E → G 동쪽 `초록 → 초록 (노랑 없음) → 초록+좌회전`.

보행 신호등은 황색 동안 from과 to 둘 다 초록일 때만 초록이고, 아니면 빨강입니다.

### 보행 신호 점멸

- **다음 스테이트에서 빨강이 되는 보행 초록**만 스테이트 시간의 절반이 지나면 점멸합니다 (0.5초 꺼짐 / 0.5초 켜짐, 빨강은 꺼진 채).
- 다음 스테이트에서도 초록인 보행 신호(예: 주간 E → G의 South walk, 야간 A → C의 West walk)는 점멸 없이 계속 켜져 있습니다.

### 주간 ↔ 야간 전환

시계가 08:00 / 23:00을 지나거나 +1시간 버튼으로 경계를 넘으면, **지금 스테이트(와 황색)를 마친 뒤** 다른 시퀀스의 첫 스테이트로 갑니다 (주간 → 야간: B, 야간 → 주간: A).

### 긴급 차량 모드 (SM_2)

```
버튼 ─> 황색 1초 ─> state A 15초 ─> 황색 1초 ─> 원래 스테이트 (시간 처음부터)
        (지금 → A)    (남 → 북 직진)   (A → 원래)
```

- "1초 후 state A"의 1초를 황색으로 씁니다. 지금 스테이트가 A이면 바뀌는 램프가 없어 그대로 보입니다.
- 원래 스테이트는 5초 / 10초를 **처음부터 다시** 셉니다. 시계(time_keeper)는 긴급 모드와 상관없이 계속 흐릅니다.
- 긴급 모드 중에 다시 누르면 무시합니다. 황색 중에 누르면 그때 보이던 스테이트가 원래 스테이트입니다.
- 15초 A에서도 절반(7.5초) 뒤 원래 스테이트에서 빨강이 될 보행 초록이 점멸합니다.

### Text LCD

| 줄 | 표시 | 예 |
|---|---|---|
| 1 | `Time : hh:mm:ss ` | `Time : 11:48:32 ` |
| 2 | 평소 `State: x (day)  ` / `State: x (night)` | `State: A (night)` |
| 2 | 긴급 모드 `EMG  : x (...)` | `EMG  : A (day)  ` |

- 한 줄이 16글자라 교안 예시 `State : A (night)`(17글자)에서 `:` 앞 공백을 뺐습니다.
- `(day)` / `(night)`는 **시계 기준**입니다. 23:00이 되면 바로 `(night)`로 바뀌고, 신호는 지금 스테이트가 끝난 뒤 야간 시퀀스로 바뀝니다.
- 황색 동안에는 아직 지금 스테이트 글자를 보여 줍니다. 긴급 모드 첫 1초(황색)는 원래 글자, 그 뒤 15초 + 황색 1초는 A입니다.

### 시계 배율

| SW3 SW2 | 배율 | 시계 1초마다 (50 MHz) | 주간 15시간이 걸리는 실제 시간 |
|---|---|---|---|
| OFF OFF | x1 | 50,000,000 클럭 (1초) | 15시간 |
| OFF ON | x10 | 5,000,000 클럭 (0.1초) | 1.5시간 |
| ON OFF | x100 | 500,000 클럭 (10 ms) | 9분 |
| ON ON | x200 | 250,000 클럭 (5 ms) | 4.5분 |

## 모듈 구조

```
btn_hour -> btn_debounce -+-> oneshot -+-> hour_inc -> time_keeper --> hour, min, sec -+
btn_emg  -> btn_debounce -+            |                ^    |                        |
scale_sel -> 2-FF 동기화 --------------|----------------+    | is_day                 |
                                       |                     v                        |
                                       +-> emg_btn ----> traffic_ctrl --> state[23:0] (램프 24개)
                                                             |                        |
                                            disp_letter, emg_active                   |
                                                             v                        v
                                                       2번째 줄 문자열          1번째 줄 문자열
                                                             +--> lcd_driver <--------+
                                                                      |
                                                         LCD_E, LCD_RS, LCD_RW, LCD_DATA
```

### traffic_ctrl 상태(phase)

| phase | 길이 | 램프 |
|---|---|---|
| P_START | 1클럭 | 꺼짐. 시계를 보고 주간 / 야간 시퀀스 선택 |
| P_RUN | 5초 / 10초 | 지금 스테이트, 뒤 절반에 보행 점멸 |
| P_YEL | 1초 | 지금 → 다음 스테이트 황색 |
| P_EMG_Y | 1초 | 지금 → A 황색 (긴급 버튼 후 1초) |
| P_EMG | 15초 | A, 뒤 절반에 보행 점멸 |
| P_RET_Y | 1초 | A → 원래 스테이트 황색 |

- 시퀀스 위치는 `(seq_night, idx)` 두 레지스터로 기억합니다. 긴급 모드 동안 이 값을 건드리지 않아서 끝나면 원래 스테이트로 돌아갑니다.
- 타이머는 `div_cnt`(0.5초 = 25,000,000클럭)와 `half_cnt`(0.5초 단위 경과)로 세고, phase가 바뀔 때와 긴급 버튼을 받았을 때 0으로 돌아갑니다. 그래서 "버튼 후 1초"가 정확히 1초입니다.
- 램프는 `lamp_pattern` 두 개로 from / to 패턴을 만들어 위의 황색·점멸 규칙으로 섞은 뒤 레지스터로 내보냅니다.

### 50 MHz에서 달라진 점

- **LCD**: WEEK_8 ~ 10은 클럭을 1 kHz로 낮추고 `LCD_E = clk`였습니다. 여기서는 50 MHz를 1 ms 슬롯으로 나눠 슬롯마다 명령 1개를 내고, `LCD_E`는 슬롯 가운데(0.25 ~ 0.75 ms)에만 1입니다. 명령 순서는 예전과 같습니다 (DELAY → FUNCTION_SET → DISP_ONOFF → ENTRY_MODE → LINE1 ↔ LINE2, 한 화면 34 ms).
- **버튼**: 50 MHz에서는 버튼 한 번에 채터링이 수천 클럭 생기므로 `btn_debounce`로 10 ms 동안 값이 안 바뀔 때만 받아들입니다. 없으면 +1시간이 여러 번 들어갈 수 있습니다.

## 시뮬레이션 (tb_main)

`CLK_HZ = 1000`으로 줄여(설계 1초 = 1000클럭) 345초 동안 돌립니다. 시작 시각 07:59:40, 배율 x1.

| 시각 | 확인 내용 |
|---|---|
| 0 ~ 21 s | 야간 B → A (10초 + 황색 1초) |
| 20 s | 08:00:00 → A가 끝난 뒤 주간 A부터 |
| 36 s | 긴급 버튼(채터링 포함) → 36.022 s 황색, 37.022 s A 15초, 52.022 s 황색, 53.022 s F 5초 다시 |
| 45 s | 긴급 중 다시 누름 → 무시 |
| 85 s | +1시간 15번(채터링 포함) → 23:01 → D가 끝난 뒤 야간 B부터, H → B 반복 확인 |
| 170 ~ 176 s | x10 2초 = +20초, x100 2초 = +200초, x200 2초 = +400초 |
| 335 s | x200으로 08:00 통과 → E가 끝난 뒤 주간 A |

램프가 바뀔 때마다 `시각, phase, 스테이트, 램프(E/W/S/N 차량 RYGL, 보행 R/G/.), LCD 문자열`을 한 줄씩 출력하고, LCD 핀에 연결한 HD44780 모델이 실제로 받은 화면도 출력합니다. 끝에 디바운스 결과(+1시간 펄스 15개, 긴급 펄스 2개)를 확인합니다.

Vivado에서 Run Simulation → Run Behavioral Simulation을 누르면 `$finish`까지 돌고 Tcl Console에 결과가 나옵니다.

## 경계에서 보이는 동작

- 야간 A(idx 1)가 도는 중 08:00이 되면 다음이 주간 A가 되므로, 점멸하던 East walk가 다시 초록으로 켜지고 A가 황색(바뀌는 램프 없음) 뒤 주간 A로 이어집니다. 다음 스테이트를 매 순간 시계로 정하기 때문입니다.
