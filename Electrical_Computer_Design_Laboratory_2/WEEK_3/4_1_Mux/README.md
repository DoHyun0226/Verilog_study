# 4_1_Mux

2비트 데이터 4개 중 하나를 `sel`로 고르는 4:1 MUX입니다 (`case(sel)`).

## 파일

| 파일 | 내용 |
|---|---|
| `4_1_Mux.srcs/sources_1/new/Mux_4_1.v` | 설계 (`Mux_4_1`) |
| `4_1_Mux.srcs/sources_1/new/4_1_Mux.v` | 비어 있는 모듈 템플릿 (사용 안 함) |
| `4_1_Mux.srcs/constrs_1/new/Mux_4_1.xdc` | 핀 제약 |

## 입출력

| 포트 | 의미 | 보드 |
|---|---|---|
| `in0` ~ `in3` (각 2비트) | 데이터 입력 | DIP 스위치 1 ~ 8 |
| `sel[1:0]` | 선택 신호 | 버튼 SM_1, SM_2 |
| `out[1:0]` | 선택된 데이터 | LED1, LED2 |

## 참고

`4_1_Mux.v`의 모듈 이름 `4_1_Mux`는 숫자로 시작해서 Verilog 식별자 규칙에 맞지 않습니다. 실제 설계는 `Mux_4_1.v`입니다.
