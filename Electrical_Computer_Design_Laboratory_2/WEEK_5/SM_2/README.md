# SM_2

자판기 상태 머신 SM2입니다. 50원·100원을 넣어 200원이 되면 음료를 살 수 있습니다. 상태 전이를 **case + if-else if**로 구현했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `SM_2.srcs/sources_1/new/SM2.v` | 최상위 (`SM2`) |
| `SM_2.srcs/sources_1/new/SM2_one_shot.v` | 3비트 one-shot trigger (`SM2_one_shot`) |

## 입출력

| 포트 | 의미 |
|---|---|
| `A` | 50원 투입 버튼 |
| `B` | 100원 투입 버튼 |
| `C` | 음료 구매 버튼 |
| `state[2:0]` | 현재 금액 (S0, S50, S100, S150, S200) |
| `y` | 음료 출력 (S200에서 C를 누르면 1클럭 동안 1) |

## 상태 전이

- S0 → S50 → S100 → S150 → S200 순으로 금액이 쌓이고, 200원을 넘는 금액은 S200으로 고정됩니다.
- S200에서 `C`를 누르면 S0으로 돌아갑니다.

## 한계 (소스 주석 기준)

- 버튼 두 개 이상이 같은 클럭에 눌리면 A → B → C 순서로 하나만 반영됩니다.
- 200원을 초과한 금액(잔돈)은 기록하지 않습니다.

조건 연산자 버전은 [SM2_conditional_operator](../SM2_conditional_operator)입니다.
