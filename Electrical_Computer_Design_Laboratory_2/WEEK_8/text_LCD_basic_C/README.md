# text_LCD_basic_C

코드 두 줄(LINE1, LINE2의 주소 설정)만 바꿔 **텍스트를 3칸 오른쪽으로 shift**해서 출력하는 버전입니다. 결과 보고서 D (예비 보고서 C)용입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `text_LCD_basic_C.srcs/sources_1/new/text_LCD_basic_C.v` | LCD 제어 상태 머신 (`text_LCD_basic`) |
| `text_LCD_basic_C.srcs/constrs_1/new/text_LCD_basic_C.xdc` | 핀 제약 |

보드 연결은 [WEEK_8 README](../README.md#보드-연결-네-프로젝트-공통)와 같습니다.

## text_LCD_basic과 다른 점

| 상태, cnt 0 | text_LCD_basic | text_LCD_basic_C |
|---|---|---|
| LINE1 주소 설정 | `1000_0000` (0x80 → 주소 0x00) | `1000_0011` (0x83 → 주소 0x03) |
| LINE2 주소 설정 | `1100_0000` (0xC0 → 주소 0x40) | `1100_0011` (0xC3 → 주소 0x43) |

문자는 주소 카운터 위치부터 차례로 써지므로 시작 주소만 3 늘리면 두 줄 모두 3칸 오른쪽에서 시작합니다. 문자 데이터와 상태 전이는 그대로입니다 (LINE 한계값도 교안과 같은 20).

## 화면

```
+----------------+
|    HELLO WORLD!|   0x03 ~ 0x0F에 " HELLO WORLD!" (13글자)
|   2023440075 YD|   0x43 ~ 0x4F에 "2023440075 YD"
+----------------+
```

- 각 줄 20글자 중 cnt 14 ~ 20(0x10 ~ 0x16, 0x50 ~ 0x56)은 화면 밖입니다.
- 아랫줄은 학번 + 이니셜이 14글자라 마지막 `H`가 0x50(17번째 칸)으로 밀려 보이지 않습니다. 교안대로 3칸을 미는 것이 목적이라 그대로 두었습니다.

## 시뮬레이션

LCD 모델 테스트벤치(2-line 모드, 저장소 미포함)로 확인한 화면: 윗줄 `"    HELLO WORLD!"`, 아랫줄 `"   2023440075 YD"`.
